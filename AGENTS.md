```text

→ save isolated Production configuration

→ freeze configuration revision
```

Make Production is the sole Production-wide execution transition.

A completed Job is not automatically an accepted result. Revisions create new immutable Runs. `Keep everything except X` is a delta revision that locks every previously accepted dimension except the named change.

Production-specific choices do not become Actor memory without an evidence-backed, Human-approved `ActorUpdateProposal`.

## Gummy Box rule

A Local Gummy Box exists automatically and remains useful without an external account.

```text
Local Box       authoritative by default
Managed Box     explicit opt-in
GitHub          optional scoped connector
Google Drive    optional scoped connector
```

Normal onboarding must not ask the user to create GitHub Apps, PEM keys, installation IDs, repositories, buckets, deployment projects, or environment variables.

Provider scope is limited to the selected Box root. Connecting a provider does not silently make it authoritative. Authority changes, migration, synchronization, and deletion require explicit Human review and Receipts.

Preserve IDs, revisions, hashes, rights, provenance, byte integrity, and existing local data. Backup export/import is inspect-first, versioned, idempotent, conflict-safe, and recoverable.

## Truthful capability states

Every route is visibly and structurally one of:

- deterministic simulation/demo;
- connected and ready;
- connected but degraded;
- capability required/unavailable;
- blocked by authority/policy;
- running;
- completed awaiting Human acceptance;
- failed;
- denied;
- cancelled;
- recovery required;
- expired.

A simulator is never described as a real provider. A detected runtime is not automatically authorized. A missing provider key, ComfyUI, Blender, or optional connector does not stop unaffected release work.

Finish adapter code, deterministic tests, truthful unavailable UI, and a live-smoke command; mark the live claim `NOT CLAIMED` or exact `BLOCKED` and continue.

## Security boundaries

- keep provider secrets outside browser JavaScript, source maps, logs, fixtures, backups, and Receipts;
- keep local companions loopback-only by default with authenticated short-lived sessions and strict origins;
- expose named operations/workflows only—never arbitrary shell, Python, workflow JSON, filesystem, device, or process access;
- validate schemas, versions, sizes, hashes, paths, ownership, expiry, idempotency, locality, cost, rights, and retention;
- recover ambiguous external Jobs before any resubmission;
- do not silently retry consequential ambiguous calls;
- downloads/imports begin untrusted and quarantined;
- no source or accepted Asset is overwritten;
- revocation blocks future work while preserving truthful prior evidence;
- do not claim browser delivery or Linux hosting alone makes the product secure.

## Hard stops

Stop the affected unsafe mutation and return exact evidence when:

- data may be lost or ambiguously migrated;
- source or accepted Assets would be overwritten;
- Actor/Agent or authority boundaries collapse;
- configuration would execute;
- a Work Order or application self-authorizes;
- secrets enter client-visible material;
- a local bridge becomes generic execution;
- cost/rights/locality cannot be enforced;
- an ambiguous provider call may be duplicated;
- simulated and genuine results cannot be distinguished;
- specialist evidence would be flattened;
- historical 3D Bee identity would be destroyed;
- tests are being skipped/weakened for green status;
- a claim exceeds executable evidence.

A blocker in one optional live lane does not authorize abandoning unaffected phases.
