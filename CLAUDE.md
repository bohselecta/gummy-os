# Gummy Build Orientation

Gummy is not another web desktop and not another chatbot wrapper. It is a familiar computer surface whose intelligence, social graph, software integrations, and enterprise controls share one capability-based protocol.

Prioritize complete causal loops:

```text
user intent → scoped authority → visible operation → artifact or relationship change → Action Receipt
```

The scaffold is deliberately dependency-light. Add a framework only when it improves maintainability without weakening forkability, startup speed, or inspectability.
