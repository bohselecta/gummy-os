## Promise

```text
NO ORPHANED WORK.
Your work should not disappear into AI chats.
```

Gummy keeps people, specialists, Work Orders, Returns, and Receipts inside living Productions. Configure freely. Nothing runs until you choose **Make Production**.

## What it is

A browser-delivered personal creative computer. Persistent **Actors** can be opened and connected to executable **Agents** under Human-controlled **Master Control**. Familiar computer surfaces stay: Canvas, windows, files, applications, and a system bar.

It is not a generic chatbot, storage client, or project manager with AI bolted on.

## How a stranger starts

1. Open [www.mygum.my](https://www.mygum.my/).
2. Choose Night or Day Gummy. Create a Local Gummy Box — no external account required.
3. From the guide doorway, open the **Demo Production**:  
   *Create a collaborative 30-second AI video with @Hayden, @Bob, specialists, and a labeled Demo Worker.*
4. Follow Command Center lanes: Now / Next / Delegated / Review / Blocked / Done.
5. Approve Make Production → inspect Return → Accept once → Resume the saved group.

```text
IDENTIFY → INTEND → MAKE → RETURN → ACCEPT → RESUME
```
