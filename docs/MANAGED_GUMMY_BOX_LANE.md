# Managed Gummy Box Is a Subsystem Lane

The user-first managed-storage architecture is one optional Gummy Box delivery lane. It is not a replacement definition of Gummy OS.

```text
Gummy OS
└── Gummy Box
    ├── Local Box — automatic and authoritative by default
    ├── Managed Box — explicit opt-in
    ├── GitHub connector — explicit opt-in
    └── Google Drive connector — explicit opt-in
```

Cloudflare or another managed provider supplies storage, synchronization, and deployment infrastructure. It does not replace Gummy Canvas, Gummy Bar, Gummy/Glopper identities, the local Operator, VideoBoss, ImageHoss, 3D Bee, Actors, Bowls, Rooms, Social computing, protocol, permissions, provenance, or evidence.

Any implementation of the managed lane must:

- leave Local Box useful without an account;
- show authoritative and mirror locations;
- keep provider permission scoped to the selected Box;
- require explicit Human approval before changing authority or synchronization;
- preserve IDs, revisions, hashes, rights, provenance, Receipts, and existing local data;
- pass the full-product preservation gate.
