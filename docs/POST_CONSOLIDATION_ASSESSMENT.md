## Important implementation limits

### The Production runtime is still a vertical proof

`src/core/production-runtime.js` intentionally contains fixed Ranch Day participants, fixed personal IDs, fixed service definitions, fixed setup order, and deterministic reference execution.

That is acceptable evidence. It is not yet the generic public Production engine.

Do not generalize everything before the first real adapter proves which abstractions are necessary.

### ImageHoss is currently represented too narrowly

The deterministic Gummy OS definition treats ImageHoss primarily as reference preparation.

The real `bohselecta/imagehoss` product already supports:

```text
Direction → References → Route → Generate → Compare → Accept → Handoff → Receipt
```

The first real adapter must expose that complete useful relationship without copying ImageHoss into Gummy OS or reducing it to a prompt box.

### The Living Self Page is doctrine, not runtime yet

The current Actor App Surface proves persistent scoped windows and Production contexts. It is not yet the evidence-aware Living Self Page.

The Living Self Page should be built after at least one real specialist app can create meaningful, correctly attributed evidence.

### Canonical documentation still needs a later synchronization pass

Several older sections in `README.md`, `AGENTS.md`, `docs/ARCHITECTURE.md`, and `docs/PROTOCOL.md` still foreground the pre-Production standalone Work Order mission or omit newer Production artifact families.

The new architectural-center ruling and Cursor rule prevent immediate drift. Before the real ImageHoss adapter is called complete, update those canonical documents so read order, artifact families, current priority, and implementation truth match the merged runtime.

### Native and public-network claims remain staged

The consolidated proof does not establish:

- a real native Bridge;
- real ImageHoss/3D-Bee/VideoBoss execution inside Gummy OS;
- cross-device encrypted Actor synchronization;
- public `@address` federation;
- the Actor discovery network;
- managed Gummy Box production infrastructure;
- public Production licensing or acquisition;
- the Living Self Page knowledge-extraction pipeline.

Do not imply these are already live.
