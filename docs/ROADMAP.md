## Released target

The shipped result is the stable, local-first Gummy OS v1 product.

A clean user can:

```text
open Gummy OS
→ understand it within seconds
→ begin locally without an account
→ start a blank or sample Production
→ configure specialists without execution
→ inspect route, cost, locality, rights, locks, and expected outputs
→ Make Production
→ receive truthful results, Returns, and linked Receipts
→ compare and Human-accept outputs
→ close and return to intact state
→ export and restore a complete Local Gummy Box backup
```

Live specialist capabilities execute only when their trusted runtime/provider is present. Missing optional external capability produces a truthful unavailable state, not a fake success or a failure of the whole local release.

## Execution policy

The phases run sequentially in one sustained Codex turn with checkpoint commits. They are evidence boundaries, not mandatory conversational pauses.

Older proof-stage instructions to stop after a contract proposal, one vertical slice, a gap audit, or an intermediate founder review are superseded for this release program.

No phase may supersede:

- Human authority;
- Actor/Agent separation;
- rights, privacy, cost, locality, and retention;
- source immutability;
- Make Production execution semantics;
- Human acceptance;
- specialist identity and native evidence;
- brand locks;
- automated acceptance and truthful limitations.
