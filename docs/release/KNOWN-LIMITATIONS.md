# Known Limitations — Gummy OS v1

Honest limits of the shipped personal release. Do not treat absence as a silent success.

| Area | Limitation |
| --- | --- |
| Demo Worker | Deterministic local demonstration only. Not a live model provider. Charges $0.00. Publishes nothing remotely. |
| Live Google Agent Platform | **NOT CLAIMED** |

## Product behavior limits

- Opening or configuring a specialist does **not** spend money or start a creative Job.
- Accepting a result does **not** publish it. Distribution is a separate Human decision.
- Production-specific settings do not become Actor memory without an approved `ActorUpdateProposal`.
- Composer edits remain proposal-only; they cannot Run, Lease, Grant, or charge.
- Local Gummy Box data lives in this browser (IndexedDB / OPFS). Clearing site data loses local state unless a backup was exported.
- Optional GitHub / Drive connectors are scoped and opt-in; connecting a provider does not silently make it authoritative.
