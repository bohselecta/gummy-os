# Product Readiness Audit

Date: 2026-07-27  
Branch: `codex/final-release-2026-07-27`  
Baseline: `c1279e5f45d51e64febf4c29a701bbd5b21e62f1`

## Scope

The complete browser product was exercised in clean Playwright contexts at desktop
and phone widths, in Night and Day Gummy, with reduced motion, keyboard navigation,
offline operation, denied approval, quarantine, revocation, persistence, and
completed Return states. The deterministic suites also cover failure, cancellation,
stale leases, migration, source immutability, and restart recovery.

## Release blockers

None remain from the readiness-only pass. External specialist runtimes are not
installed on this machine and therefore remain explicit capability limitations,
not hidden or simulated claims.

## Release requirements

- **Closed:** Meshmallow is the current public identity. Stable `actor:3d-bee`,
  `app:3d-bee`, repository, protocol, and historical evidence identifiers are not
  rewritten.
- **Closed:** Public specialist descriptions now describe the complete product
  relationships instead of internal `reference-preparation` and
  `scene-preparation` roles.
- **Closed:** Each unavailable specialist explains what works locally, what
  connection is needed for real execution, and the safe next action.
- **Continues in Phase 2:** Replace the Ranch Day-only doorway with blank and safe
  sample choices while retaining Ranch Day as a compatibility fixture.
- **Continues in Phases 4–6:** Replace generic configuration fields with
  specialist-native structured editors and compiled previews.
- **Continues in Phase 7:** Make backup inspection and clean-context restore
  first-class Local Box operations.

## Deferred enhancements

- Managed Gummy Box hosting and account-based sync.
- Live ImageHoss output without a trusted bridge and ComfyUI.
- Live VideoBoss output without a server-side provider credential.
- Live Meshmallow output without Blender.
- Social discovery and hosted Gummy Rooms.
- Physical realization and manufacturing.

## Rejected drift

- Flattening any specialist into a generic prompt box.
- Renaming stable 3D Bee IDs or rewriting historical evidence.
- Making configuration or surface opening execute work.
- Treating deterministic demonstration output as live provider output.
- Requiring GitHub, Drive, Vercel, or an account for first use.
