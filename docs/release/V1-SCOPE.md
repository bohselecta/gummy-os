# V1 Scope

**Product:** Gummy OS  
**Releases covered:** `v1.0.0` (Calm Workspace) and `v1.0.1` (stranger-loop completion)  
**Canonical URL:** https://www.mygum.my/

## In scope (shipped / preserved)

- Browser Gummy OS shell: Canvas, Bar, windows, Glopper, Master Control
- Local-first Gummy Box without requiring an external account
- Actors, Agents, Molds — never collapsed
- Productions with configure-without-execute and **Make Production** as the sole execution transition
- Shared Vision → Agreement → Formation → Run → Return → Accept → Resume
- Living Collaboration Demo Production (collaborative 30-second AI video) with labeled **Demo Worker**
- Command Center as a generated non-executing projection with Now/Next/Delegated/Review/Blocked/Done lanes
- Returns, Receipts, Work Orders, Leases, Grants
- First-party specialist Actors and deterministic demonstration routes: ImageHoss, VideoBoss, Meshmallow (`3d-bee`)
- Night Gummy / Day Gummy brand and production brand assets
- Calm Workspace continuity and Local Box backup export/import foundations
- Automated unit, integration, and browser acceptance for the personal release path

## In scope for v1.0.1 specifically

- Stranger-readable doorway and Demo Production CTA
- Demo Worker plain-language labeling and disclosure
- Command Center lane projection
- Provenance and release documentation matching the software
- Stranger-loop automated tests

## Out of scope / not claimed

- Live Google Agent Platform, Agent Identity, Memory Bank, provider telemetry
- Live MCP host/server App execution
- Public-deploy live ComfyUI, fal.ai, or Blender execution without authenticated local/server bridges
- Authenticated live Gummy Rooms service runtime
- Enterprise federation, billing, marketplace
- Broad native OS control, finished-game generation, physical manufacturing
- Final Underground wallpaper art as locked canon
- Rewriting or replacing immutable `v1.0.0` history

Optional live integrations remain archived in `docs/roadmap/OPTIONAL_POST_V1_RUNTIME_INTEGRATIONS.md` and require separate authorization.

## Preservation law

```text
Simplify the doorway. Do not flatten the house.
```

v1.0.1 improves the doorway. It does not redefine Gummy OS as a chatbot wrapper or drop protected pillars.
